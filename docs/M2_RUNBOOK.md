# M2 内容工作台运行与使用

更新：2026-10-02。M2-F01–M2-F06 已建立可运行链路；真实 AI 已接入，授权 63 页课件批量任务与原页 5–14 正式审核准备见本轮证据。教师课程审核、正式试听核查、冻结与阶段退出仍待完成。M1 人工评审保持待完成。

## 启动

在仓库根目录执行：

```powershell
.\.venv-m1\Scripts\python.exe tools/m1_pip_direct.py install -r requirements-m2.txt
if (-not (Test-Path config/m2.local.json)) { Copy-Item config/m2.example.json config/m2.local.json }
.\tools\m2_start.ps1
```

已有本地配置时不要覆盖。启动器仅绑定 `127.0.0.1:8765`，默认自动打开工作台，用 120 秒内有效、使用一次即失效的票据登录；长期访问令牌不打印，仍只在私有存储。登录后 fragment 立即清除，后台继续校验本机会话/Host/Origin。重复运行启动器会打开已运行服务，不另建工作进程。使用 `-NoBrowser` 可只启动后台。前端需 Node；启动器在缺少构建或源文件更新时执行依赖安装及构建。后端修改后重启服务。停止使用 Ctrl+C。

课程列表以“新建课程/继续制作”为主操作，复制/删除在“更多”内；开发测试项目折叠显示，原项目与证据保留。依次按“上传素材→生成并审核讲稿→试听→生成前检查”操作；高级配置按需展开。课时外跳过页默认收起，可勾选显示。

正式前端采用 Vue，后端 FastAPI。所有 API 和文件预览需要本地教师会话，拒绝跨站 Origin 和非本机 Host。此版本面向当前 Windows 用户的单机工作台，尚不提供多人账号/远程部署。`storage/m2` 自动移除继承 ACL，仅当前 Windows 用户、SYSTEM 和 Administrators 可访问；外部存储必须是同样支持 ACL 的受控目录。

## 操作流程

2026-10-09 讲稿链路更新：本机配置启用 `ai.pipeline.enabled:true` 和 `text_model:glm-4.7-flash`，视觉模型继续理解原页，文本模型生成自然中文正文和独立教学核查。正文先保存，读法及逐句对应由本机规则派生；未知公式/术语保持原文并标为待核对。费用权限保持 `allow_paid:false`，没有付费回退。

若页面显示“教学核查尚未完成”，可在高级逐页讲稿中点击“仅重试教学核查”，也可填写核查表后保存并由教师确认。该操作保留已保存正文。服务繁忙或缺正文时按提示有限重试缺失步骤；已完成页面保留。配置切换影响新任务，旧稿与历史视频不自动重写。完整未审核草稿可以继续制作，正式审核/冻结仍须完成核查及教师评审。

1. 新建课程，填写素材来源、处理授权记录及同一教师标识。上传课件、参考语音及照片或视频；照片/视频可同时准备，课程设置中明确选用其中一种。
2. 等待真实校验任务。PPTX 分别保存结构、XML、图片关联和 PowerPoint 原页 PNG；旧 PPT 尝试隔离转换，失败请另存 PPTX。默认 50 页，可在本地配置调整，容量上限也可配置。
3. 在参考语音卡片明确选取子片段并填写对应文字；GPT v2 当前限制 3–10 秒，原音频保留。照片可裁剪，视频可选取 5–60 秒并播放真实序列。原件、派生文件、起止时间/裁剪坐标及摘要分别保存。
4. 工作台左侧选择原页对应片段，中间看原课件，右侧编写显示稿和读法稿。编辑约 900 ms 后自动保存，也可立即保存。旧版本请求冲突会阻断，先重新打开项目，再核对本地稿保存。
5. 三个入口：AI 新版本、备注原文、外部逐页稿。空/占位备注明确阻断。原文和外部稿保持字面内容，不自动润色；重新生成与回退均追加版本。外部稿先下载映射模板，填写每页稳定 `source_page_id`，精确覆盖全部原页；重复、遗漏、错位阻断。重排不改变 ID；合并/拆分后按片段编辑，禁止按页号静默猜测。
6. 页面可跳过、移动、合并相邻片段或拆成多个稿件。合并来源可有多页，选择播放原页；拆分保留来源和顺序。导入、过渡、总结作为片段用途保存，教师编写相关讲解，不生成通用套话。
7. 教师核查知识点、问题/答案/原页来源、术语/数字/公式读法，待确认项清零后填写核查记录并锁定版本。至少 5 个理解问题由生成前预检检查。修改已确认稿形成新版本，撤销当前确认，旧审核版本仍可追溯。
8. 课程默认设置由系统→项目→片段继承。可单页/勾选范围/全课批量覆盖人物显隐、位置、尺寸、语速、前后停顿和术语读法；恢复继承会移除该页覆盖。布局只标重合成；语速/停顿变化使试听过期；术语变化形成待审核读法新版本。
9. 对确认稿生成真实试听。界面显示真实任务阶段，不显示递增伪百分比。播放并核查音色、术语、漏句和重复，填写记录后确认。模型工具检查不替代人工评审。
10. 运行生成前预检，定位修复阻断项，创建并下载不可变内容快照供 M3。当前不提供整课数字人合成、MP4/SRT 导出；这些在 M3 实施。

显示教师区域的单页布局预览是编辑提示；视频模式最终使用源视频序列，布局示意不是数字人视频生成成功。

## 停顿与外部稿契约

详见 [M2 接口与数据契约](../specs/M2-content-contract.md)。只识别 `{{pause:1.0}}`（0–10 秒）为控制指令。显示文本、读法文本与控制事件分别保存；`[0,1]`、`[1,2,3]`、`[1]`、`(a+b)` 均保留。术语替换只作用于读法稿；不递归级联替换。停顿按读法字符位置拆成 speech segments，在同一原生 TTS 引擎中逐段推理并按实际采样率插入零样本；不把控制标记朗读出来。语速传入 GPT-SoVITS `speed_factor`，最终时长来自实际输出。

## AI 服务配置

本机已复用存在的 ZHIPUAI_API_KEY 配置 GLM-4.6V-Flash。官方 [模型说明](https://docs.bigmodel.cn/cn/guide/models/free/glm-4.6v-flash) 标为免费、支持图像及 Base64；地址为 `https://open.bigmodel.cn/api/paas/v4`。本地配置为 `allow_external:true/allow_paid:false`，这一免费例外仅允许该精确地址和模型。其他外部模型仍需既有明确授权和 allow_paid；预检不调用生成。密钥只读环境变量，不显示或保存到课件/证据；request_options 可配置 thinking/max_tokens 等兼容参数。

在整份课件项目中点击“生成当前课时逐页讲稿（63 段）”即可批量生成。每页保存独立任务，状态与数量来自真实数据库；429/503 最多等待重试三次，其他失败明确显示，可重试单页或所有最新失败页。输入保存整课正文大纲、当前原页图/正文/备注和前后页正文，排队期间编辑导致冲突会阻断旧输出。AI 原始响应仅保存在受控项目目录，来源/响应 ID/usage/摘要可追溯。已有人工稿不会被设成 AI 当前稿，AI 保存为候选，预览后主动采用；旧版本始终保留。

正式验证课时由用户选定为原页 5–14“无线接入与多址技术”。教师逐页填写知识点、术语/数字/公式读法、理解问题及答案原页来源，逐项核对待确认内容；保存核查草稿不等于确认。修改读法表后同步核对实际读法稿，系统不替教师判断。至少 5 个问题且全部活动页审核完毕才可正式冻结。未确认稿可生成真实草稿试听，明确标注未审核，不计入正式就绪；确认稿再生成正式试听，逐项勾选音色、读法、无漏句、无重复并填写记录。没有教师判断时保持待审核，不能自动生成通过快照。

本机已有“Lecture 2 · 整份课件 AI 草稿”（63 页）和“无线接入与多址技术 · 第 5–14 页 · 待教师审核”（10 页课时）两个课程项目。正式课时已具备 10 问和 10 份真实草稿试听，在工作台展开“审核参考清单”可查看并下载具体待核查项目。拼音/英文的中文术语读法会提示核对；修改表单后可点击“将核查读法应用到当前页”，查看“实际朗读文本与停顿”，再重新试听。该动作追加版本，不代替确认。正式审核和试听核查完成后才能冻结，当前仍阻断。

本机已实测 GLM-4.6V-Flash 原生 `response_format:{type:json_object}`，保存到 request_options，避免未转义引号破坏返回结构。生成质量、数字/单位的所属概念及拼音读法仍由教师核查，结构合法不代表教学正确。

AI 输入包含当前原页图、正文、原备注、前后页摘要、课程受众/详略/时长及片段用途。返回稿件及知识点、问题、术语、补充解释和待确认项；教师确认前始终为草稿。服务不支持图像、超时或返回格式错误会失败，旧人工稿不会覆盖。配置需重启后端生效。

## 持久化、复制与删除

SQLite 使用 WAL 与写事务；项目配置、素材、原页、片段、版本、审核、任务和快照保存到磁盘。刷新/重新打开不丢内容。任务排队记录持久化；服务重启后仍在 running 的内容任务标记中断失败，排队任务继续处理。M2 不承诺 M3 的原生中断、自动重试和片段恢复。

复制时为素材、原页和试听建立物理副本，保留 `source_project_id`，使用新的项目/片段 ID。没有共享文件引用；删除项目清理自身目录、任务与快照，其他副本不受影响。活动任务阻断复制和删除。删除检查绝对目录边界与重解析点。教师素材/文本、原生日志、会话令牌和密钥均不进入 Git；默认不训练、不上传、不自动保留共享素材。
