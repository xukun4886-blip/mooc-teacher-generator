# M4 预验收与待确认材料

本轮只预验收，M1–M4 退出未通过。建议阈值维持 [M4 spec](../specs/M4-acceptance.spec.md)，本文件不是已冻结决定。工作台普通流程先生成未审核草稿，之后教师主动核查，不代填任何评审。

## 可提交的评审材料

使用高级入口保存本人试听及内容核查。真实照片/视频输出的位置、任务和摘要见 [长课记录](evidence/M3/external-long-courses.json)；原GLM-4.6V新上传失败及重试见 [原失败记录](evidence/M3/long-course-validation.json)，免费4.1V两页新上传闭环见[功能报告](evidence/M3/fresh-ai-validation.md)。十页外部稿是独立媒体预验收课程，两页AI是功能样例，均不代表内容审定或正式任务。

每个正式课时需教师核定知识点清单、关键数值/公式/术语、至少五个有答案和来源页的理解问题。每位教师至少五段十秒样片，由本人及另外两名评审分别评价音色、形象、自然度。连贯性和可理解性由三名评审评分。没有提供评分时保持空白，不能把工具检查或模型自评填为人工结论。

受控原始材料的路径与摘要见[评审材料索引](evidence/M4/review-materials.json)：含六个问题/答案草案/原页来源及三种讲稿来源的实际保存样例。均为待审，分数、评审人和确认保持空白。

成片完成后运行 `.venv-m1\Scripts\python.exe -m tools.m4_review_pack`，为每条路径创建绑定视频摘要的独立待评表，已有填写不覆盖。每表包含按视频摘要固定种子随机抽取的20句实际字幕、20个口型核查候选导航点、5段十秒试听窗口及三名评审空白评分。字幕候选起点不是已测得的发音或嘴型起点，须人工看波形和逐帧选择清晰发音；不可测点记录原因并补足。两条路径属于同一教师，不能充当两名教师。未审核工程课程可供熟悉和发现问题，不计入正式基线验收数量。

## 建议冻结版本（待用户决定）

| 项目 | 本轮呈现的建议值 |
| --- | --- |
| 样例 | 3 份授权课件（文字/图表/公式），至少 2 名授权教师；照片/视频各 6 个约 10 页/3 分钟有效任务；另 1 个接近实际配置上限的长任务 |
| 教学 | 覆盖率 ≥95%；关键术语/数值/公式无实质错误；待确认项清零；每课时 ≥5 题 |
| 评分 | 各维度分别五分制；本人+2评审音色/形象/自然度各平均 ≥3.5；3名评审连贯性/理解性各平均 ≥3.5 |
| 口型 | 每条路径 20 个清晰发音起点，至少 90% 可测点误差 ≤200 ms |
| 字幕 | 随机 20 句，起止偏差分别统计，至少 90% ≤300 ms；重点区域无遮挡须人工确认 |
| 结束时差 | 扣除明确片头片尾后音视频结束时差 ≤100 ms |
| 首次成功率 | 12 项有效任务 ≥11 项首次完成；恢复完成保留首次失败，不计首次成功 |

建议统计规则供确认：维度分数按原始评审逐项算术平均，不合并多个维度抵消低分；口型不可测点须标时间、原因和原始截图并补充样点到每条20个可测点；字幕每句分别测开始和结束，保留原始误差与抽样方法。排除预检正确阻断、不具备有效输入的任务时保留独立清单。资源报告使用固定设备/版本，设备显存与模型 torch 峰值区分，缓存重合成不冒充模型预热。

需要用户补充或决定：第二名教师及其授权照片/原视频/声音；足额三份授权课件；评审人姓名/身份与实际评分；上述建议指标及统计规则是否冻结；接近配置上限的长任务用哪份素材和时长；新的设备或另机重建条件。现有一个教师、一份课程加工程课件，不满足正式样本数量。高清照片是提高人物质量的建议，目前原照片180×168，先保留实测，不能据此降低阈值。
