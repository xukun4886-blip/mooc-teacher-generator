# 教师使用与异常处理

启动见 [部署说明](DEPLOYMENT.md)。普通操作保持：上传教师图片或原视频（二选一）、课程 PPT 和参考语音 → 点击“生成慕课视频” → 播放下载 → 教师主动确认。参考语音只用于音色，不是完整课时录音。仅使用已获授权且人物/声音属于同一位教师的素材。

上传后可预览原人物、课件缩略图和参考语音。后台自动识别参考片段文字、生成缺失讲稿，并排队生成语音、人物、字幕和视频。制作时间取决于实际模型和硬件；页面显示真实阶段和已完成页数，关闭页面或断连不会取消任务，重开可继续查看。

成片明确标识“未审核草稿”。播放检查课程内容、术语读法、人物/音色、口型、字幕和原页；下载 MP4。四类文件（MP4、SRT、讲稿 Markdown、任务 JSON）在高级成果入口可下载。教师确认区默认未选中；完整观看并核查后由本人提交确认。该确认绑定这一份成片和输入，修订后应重新制作，旧确认保留历史；确认不会自动满足正式验收。

需要改稿、调整布局、选择参考片段或核查模型时，进入“高级设置 → 打开高级编辑与管理”。三种稿源可用：AI 草稿、备注原文、外部逐页稿。原文和外部稿保留原字面内容；外部稿需精确匹配稳定来源页 ID，不按页位置静默猜测。显示稿、中文读法与 `{{pause:N}}` 控制事件独立保存；`[0,1]`、`[1,2,3]`、`[1]` 不删除。高级编辑/人工评审不是普通制作的前置步骤。

| 现象 | 处理 |
| --- | --- |
| 浏览器连接被拒绝 | 运行启动器；检查 `/api/health` 和启动日志。若端口被其他程序占用，使用另一个端口并通过同一启动器打开。 |
| 课件解析失败或格式不支持 | 检查原件；旧 PPT 可另存为 PPTX。空闲时可直接点课程 PPT 的“重新选择”，系统自动切换到新课件课程并沿用已就绪人物和参考语音，旧课件、讲稿和成片保留。生成或处理文件时需等待完成。 |
| 提示参考语音不足或不清楚 | 换清晰连续普通话，或在高级入口修正实际选取片段对应文字；不填无关文本。 |
| 讲稿服务繁忙（429） | 已生成稿保留；等待后点击重试。每项制作最多三代执行，不无限重试、不切换付费服务。次数用尽时需修正输入，或等待管理员检查服务配额。 |
| AI 格式/字幕对应错误 | 页面显示失败的原页码。系统会有限纠正格式，拒绝数组、缺失正文或达到输出长度上限的结果；只恢复完整正文的明确句界，不删句补句。已完成讲稿保留，可直接重试；次数用尽后按钮禁用，由维护人员修正服务配置，或在高级入口提供完整逐页稿。 |
| 显存不足/超时/模型失败 | 任务失败并定位阶段；检查当前资源及模型配置后有限重试，复用兼容有效媒体。不会换成普通声音、静态照片或无人物来显示成功。 |
| 取消暂未结束 | 当前模型到可中断点后停止，不再创建下一片段。页面显示实际状态；取消后重新制作是新任务。 |
| 中途重启 | 自动核对已保存片段与摘要，再从未完成阶段恢复；恢复次数有限。首次失败和重启记录仍保留。 |
| 下载报摘要变化或文件损坏 | 不继续分发该文件；记录任务号，检查受控存储，再重做受影响结果。 |
| 人物不清晰或重点被遮挡 | 更换高清已授权照片或进入高级布局调整；1080p 画布不能恢复低清素材细节。人工核查重点区域后再确认。 |

交给维护人员时提供课程名、任务号、错误码和发生阶段。不要发送密钥、永久会话令牌、完整教师素材或原生日志到公开渠道。授权、质量评分与正式指标冻结见 [评审材料](M4_REVIEW.md)。
