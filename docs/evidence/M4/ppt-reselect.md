# 课程PPT重新选择修复 · 2026-10-09

用户截图显示人物与参考语音可重新选择，但有效课程PPT按钮灰色。原因是OneClick.vue永久禁用state=ready的PPT，同时旧上传接口禁止覆盖有效课件，只有高级新建课程才能更换。这增加了普通用户操作，现已修复。

空闲时直接点击“重新选择”：后端原子建立关联课程与新PPT处理任务，物理复制当前已就绪的所选教师形象和参考语音（原件、已选片段、对应文字、摘要）。前端切换课程URL和继续制作记录。原课程的素材、讲稿、审核及成片保留；新课件重新解析渲染，不继承旧稿、来源页映射、审核或媒体缓存。生成/排队/素材处理中仍临时禁用，防止修改正在消费的输入。无需额外确认或高级步骤。

关联M2-F01/F02/F06、FR01/FR02/FR03/FR06/FR19、AC01/AC09/AC17、NFR01/NFR05/NFR08；规格和契约同步到[一键流程](../../../specs/ONE_CLICK_FLOW.md)与[M2契约](../../../specs/M2-content-contract.md)。

- [7项专项](ppt-reselect-tests.xml)通过：拥有独立已选素材、旧稿/输出保留，源删除后副本可用；空文件、旧revision、忙碌、教师文件摘要变化失败无新课程；高级覆盖继续阻断。视频模式归档复制专项核查只携带当前视频/选取，不携带未选照片；归档替身不计模型验证。
- [首次测试](ppt-reselect-tests-first.xml)保留1失败/12通过。失败为测试直接索引稀疏配置的mode字段；改为使用既有有效配置继承接口后专项6项全通过，未删除失败证据。
- [46项内容/一键流程回归](ppt-reselect-regression.xml)通过（58.10秒，包含此前6项专项）；补充视频归档专项后7项专项通过，重复次数不相加为独立用例数量。Vue生产构建通过；[服务启动](ppt-reselect-startup.json)检查队列空闲后加载新后端，原两条十页成片及项目不变。
- [真实PPT核查](ppt-reselect-real.json)与[浏览器记录](ppt-reselect-browser.json)：原2页课程通过文件选择器上传授权原页5–14的10页PPT，自动切换新项目；实际原页解析渲染完成，按钮可重选、“生成慕课视频”可用，刷新恢复。当前所选人物模式为照片；两种模式共用同一素材复制逻辑，未将未选视频带入新课程。所选形象、原/选参考音频摘要与原课程一致，新讲稿版本数0；原项目指纹和旧MP4下载摘要不变。
- [截图](ppt-reselect-browser.png)记录修复后的按钮及三项素材。未启动新AI或媒体生成，未填写教师确认，不用此检查宣称模型质量或M3/M4退出通过。前序85项全套是前序实现证据，本次修改的回归另存，不覆盖旧报告。

原课程在验证开始前已经由用户更换过人物，故其旧视频显示输入已变化；本次以验证开始时的实际项目指纹为准，未恢复或覆盖用户新素材。新课程只沿用当前所选人物与音色。
