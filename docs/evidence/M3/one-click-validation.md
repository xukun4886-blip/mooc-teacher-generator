## 实施结果

首页三张上传卡与一个生成按钮，上传后显示原图/视频、原 PPT 页数与缩略图、参考语音播放器。后台自动准备参考音色、按原页图文和备注生成缺失讲稿、逐页真实语音和人物、字幕及完整视频。状态来自持久化实际页数和阶段；支持关闭页面、重开、有限重试。默认人物侧栏、字幕、普通话语速 1、1080p。视频路径使用原视频序列。

制作完整未审核草稿不要求教师先确认讲稿或样片。草稿中文水印、`preview=true`、`quality_verified=false`。成片后主动打开教师确认，勾选已观看并显式提交才保存绑定输入与成片摘要的记录；不代填逐页确认、M1 评审或正式通过。改稿后旧成片不可确认。高级入口保留原编辑/评审/模型工具。

## 真实浏览器

通过 Codex 内置浏览器逐项选择本机文件，照片与视频各一套新课程：三类原件上传/处理、两页原 PPT、参考音频可播放。真实生成进度、中文失败及重试入口可见。照片和视频继续已有讲稿项目均完成，原生播放器就绪（1920×1080、7.08 秒，无媒体错误），点击播放后时间前进；点击下载获得真实 MP4，摘要与服务器结果一致。刷新仍回到成片。教师确认勾选保持未选中，未提交任何真实教师确认。

高级链接进入原逐页工作台，保留当前项目；刷新仍保留高级入口，返回简洁制作可继续同一项目。桌面三列（实测内容宽 1265），窄屏单列（实测内容宽 375，scrollWidth 同为 375），高级设置默认关闭。启动页 HTML 不缓存，避免升级后浏览器继续使用旧入口。

## 真实媒体与边界

[真实记录](one-click-real.json) 包含实际项目/任务、参考语音自动 Whisper 识别、素材和成片摘要、逐页真实提供方及四类 HTTP 导出校验。两套“继续已有讲稿”采用原授权课程第 5、7 页与之前真实 AI 摘句，均显示教师，全部语音/人物由当前页音频独立生成，1080p、25 fps、7.08 秒，完整解码、音轨零起点、静音比 0。它们验证一键媒体制作，不混同新上传 AI 全链路。

照片使用 GPT-SoVITS + SadTalker，视频使用 GPT-SoVITS + MuseTalk 原视频序列。视频第一代第二页输出检查发生 `PROCESS_OWNERSHIP_FAILED`，未被计为部分成功；直接浏览器重试后第二代复用有效语音/第一页人物及合成，完成整片，失败历史仍保留。Windows 原生进程归属偶发失败原因尚未独立定位；若再次发生需专项排查。

两套新上传两页课件真实调用现有免费 GLM-4.6V-Flash：照片经历格式校验失败及 HTTP 429，视频已有一页真实稿、缺失页重试仍 HTTP 429。未用替身、占位稿或付费回退补齐；新上传全自动 AI 至成片目前**已实现待完整验证，外部限流受阻**。短测试目标每页 8 秒，仅用于验证，正常默认仍 45 秒。当地没有代做教师音色、身份、口型、术语、字幕或原页保真评分。
