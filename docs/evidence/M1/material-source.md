# 中国大学 MOOC 素材来源核查

2026-10-01 用户建议从 [中国大学 MOOC](https://www.icourse163.org/) 获取材料，随后确认暂时没有已授权素材。本轮查看公开官网、服务协议和官方资源接口说明，没有登录账号、绕过下载控制、下载或使用教师照片/视频/声音。

- [官方用户服务协议](https://www.icourse163.org/topics/mooc_privacy_service) 第 8.6 节将课程及声音、图片、录像等内容的权利归属平台或其他权利人，要求相关使用、修改、复制等取得书面同意。当前未取得覆盖本项目用途的权利人授权。
- [官方资源接口说明](https://docs.icourse163.org/api-doc/resource-intergration.html) 面向已获课程资源赋权的第三方客户，主要提供视频和 PDF；这不保证可取得保留备注、图表和公式结构的源 PPTX。
- [官方信息接口说明](https://docs.icourse163.org/api-doc/get-info.html) 的内容地址受后台下载权限控制，默认可为播放地址。公开可观看、可学习或允许下载不构成本轮所需的数字人/音色处理授权记录。

结论：目前该网站不能补齐“约 10 页源 PPTX + 同教师照片/视频/参考语音 + 项目授权”。需提供具体可用课程及适用授权，或使用本人/同意参与教师的自有素材。所需清单和测试稿草稿见 [M1 准备指南](../../M1_RUNBOOK.md)。这是一项素材来源缺口记录，未改变照片/视频 P0 或 M1 退出条件。
