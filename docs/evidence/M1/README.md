## 实测课件资源数值

最新成功工程运行：PowerPoint 启动并打开约 3.758 秒，10 页首次导出约 0.534 秒，同一已加载课件再次导出约 0.488 秒。此数值不是模型 warm latency，也不是整课生成性能。没有据此估算 3 分钟或 30 分钟任务。

渲染首次开发检查暴露 COM 动态属性兼容问题（HWND 获取、JobObject 参数）。已改为识别新建 PowerPoint 进程并使用拥有的 kill-on-close JobObject，成功重新执行原页导出；未保留伪成功的失败页。最后一轮联系图检查修正了工程课件的数学 XML 包装，原页显示 E = mc²；此修正只发生在自建 fixture，未修改源需求或用户课件。
