# 讲稿可靠性改造实施与验证

日期：2026-10-09。用户明确授权“实施该改造”。关联 M2-F03/F04/F05/F06、FR05/FR06/FR07/FR11/FR18/FR19/FR20、NFR03/NFR05、AC02/AC11/AC12/AC16；方法为 mooc-content-pipeline，真实语音字幕验证使用 mooc-media-pipeline。阶段退出和建议指标没有变更或标为通过。

## 已实施并启用

`body-first-v1` 将原单次大JSON拆为原页理解、纯中文正文、本机读法派生、独立教学核查。正文请求使用文本输出，只消费最终content；不消费推理字段、不抽取嵌套JSON、不补造缺句。正文先事务保存为待核查版本，核查完成后追加同正文新版本。核查错误保留正文，界面提供“仅重试教学核查”。截断、拒答、旧模板和分析杂质仍拒绝。

`local-reading-v1` 从唯一显示正文确定句界，应用配置术语和数字/单位/百分数/范围规则。原文、公式、数组和引用保留；型号、未知词与缩写发音标为待核对。保存替换区间、规则版本、完整逐句对应和控制事件，程序序列化JSON；不再让模型重复四份正文。字幕继续消费实测语音时间。确定性规则不等于语义、读法或教学质量通过。

`draft_runs` 保存固定输入、基础版本、各阶段状态/摘要、原响应、请求记录和next_retry_at。重启先校验保存响应与步骤摘要，再补未完成步骤。每阶段每任务代最多4次HTTP、最多2次格式纠正，共用预算；429/503及连接异常有限退避。AI页失败继续其他页并汇总缺页，任一缺正文页不会发布整课成功。人工稿保留为当前，AI候选追加，审核版本和历史成果不重写。

本机已启用免费视觉 `glm-4.1v-thinking-flash` 和文本 `glm-4.7-flash`；`allow_paid:false`，精确免费模型名单，无付费回退。[官方来源核查](draft-reliability-provider.json)记录实际200与文档摘要；定价依据[官方定价](https://docs.bigmodel.cn/cn/guide/start/pricing)，格式参数依据[官方接口](https://docs.bigmodel.cn/api-reference/模型-api/对话补全)与[JSON模式说明](https://docs.bigmodel.cn/cn/guide/capabilities/struct-output)。没有声称服务端严格json_schema。

## 真实模型与局部恢复

[原始12次验证](draft-reliability-real.json)来自工程课件、Lecture 8、Lecture 9的6页，各运行两轮，覆盖公式/括号、仅图片、密集数字、结束页与封面。使用隔离存储 `storage/draft-reliability/validation`，原课程数据库不写入；只发送课件资料，不发送教师形象或参考语音。

12次中正文首请求成功5次，有限请求后正文保存10次、完整教学核查8次，2次缺正文、2次正文已保存但核查待完成。53个实际HTTP请求包含6个视觉成功、10个正文成功、8个核查成功及29个HTTP429/1305；这12次中的失败均为服务繁忙，没有正文JSON格式失败。5次显式命中视觉复用，失败页另有同输入检查点复用。样本小，不能外推长期成功率。

[一次有限补验](draft-reliability-recovery.json)保留全部最初失败：图片页只补核查，正文前后摘要相同，视觉/正文请求为0；该核查第一次结构不符、随后限流，有限纠正后完成。Lecture 9第11页复用已保存理解步骤，正文和核查完成。由此隔离项目当前6页均有正文及核查，但最初12次统计没有被改成全成功。
