## 教师操作

2026-10-08 主入口已改为一键制作。普通用户只需上传教师照片或视频、课程 PPT、参考语音，点击“生成慕课视频”。页面显示真实阶段和页数，成片后直接播放下载；未审核草稿明确标识，教师确认在成片之后主动操作。新上传素材自动准备音色和逐页讲稿，讲稿服务繁忙时中文提示并直接重试；没有自动教师确认。界面底部“高级设置”可继续旧课程、新建另一门课程、进入逐页编辑和管理。已有效解析的 PPT 更换时新建课程，保留旧映射与审核。

旧版逐页审核和正式流程通过“高级设置 → 打开高级编辑与管理”进入，以下操作仍保留。成片确认绑定具体草稿，不自动替代正式验收或旧逐页核查；修订后须重生成。默认行为及接口见 [一键改造](../specs/ONE_CLICK_FLOW.md)。

沿用 [M2 指南](M2_RUNBOOK.md) 的本机启动方式：

```powershell
.\tools\m2_start.ps1
```

代码更新后须重启服务，启动器重建前端；进行中的 M3 从已验证阶段恢复。继续使用一次票据、本机会话及受控存储，不打印永久令牌。

1. 打开原页 5–14 课时，在 **05 人物与音色评审** 播放原素材、完整语音和两条真实 A/B 样片，逐项记录。可保存待评/需修复草稿；人工全部核查后主动保存完整结论，不自动替代教学确认或阶段退出。
2. 在 02/03 核查显示稿、读法稿、知识点、数字/术语/公式、问题及来源；修订并确认各页。生成当前确认稿真实试听并填写四项核查。草稿试听不计正式就绪。
3. 在 04 预检、修复阻断并冻结内容快照，新编辑不改写历史快照。
4. 在 **06 视频与成果** 选快照、核查每页显隐/位置/尺寸/侧栏或小窗/字幕区域，填写逐页重点区域无遮挡记录。生成当前页 720p 审核样片，播放核查人物/音色、口型/接缝、字幕时间和布局，主动确认。
5. 提交对应快照整课；查看真实阶段/片段计数及缓存原因，取消或失败后有限重试。GPU 与内容试听排队串行。
6. 成果就绪后整片播放、页级跳转，下载 MP4、SRT、逐页 Markdown 和 JSON。必需片段失败不会提供完整成功成果。

两稿句数不同时，填写逐句字幕对应 JSON，完整覆盖两稿；时间来自真实 TTS 采样记录，不按字数推断。内容对应、口型、句内字幕可读性及连续播放仍需教师判断。
