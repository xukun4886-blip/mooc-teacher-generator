# 数字人慕课视频闭环

读取根 [AGENTS.md](../../../AGENTS.md)、[M3 spec](../../../specs/M3-media-pipeline.spec.md) 和 [项目状态](../../../docs/PROJECT_STATUS.md)，确认模型能力与审核快照真实可用。

## 执行方法

1. 按片段编排语音、人物、字幕和合成，分别持久化状态、依赖和实际媒体摘要；文件校验/发布成功后再记录完成。
2. 使用真实音频时长构造共享时间轴，处理前后停顿、转场和字幕相对/绝对偏移；显示文本与读法文本不能混淆。
3. 照片和视频模式均生成当前口型；视频保留源动态。循环仅用于源视觉，不能循环第一段说话视频覆盖不同音频。
4. 实现版本化的幂等提交、重复消息处理、工作进程重启恢复和有限重试；取消后不创建新子任务，不让晚到旧结果覆盖终态。进度由实际片段状态计算。
5. 按 spec 失效表检验改稿、参考语音、模型、布局和前页时长；记录缓存命中原因，错误命中不能靠手工清空所有缓存掩盖。
6. 检查逐页显隐/布局、比例、重点遮挡和实际字幕对齐；四类成果版本一致。全部必需片段和最终媒体有效才完成。
7. 运行真实两条约 3 分钟链路和故障注入，记录媒体、日志、冷热启动、显存及恢复结果，更新状态。

对任务编排可用模拟适配器覆盖幂等、故障与取消，另用真实适配器验证口型、音色、字幕和合成。异常静音或失败不能以默认声音、静态人物或无人物代替成功；页面主动隐藏人物应仍有语音和字幕。

GPU 不足时按能力限制排队、降批次或暂停；不反复无限重试。缺真实模型时继续完成独立编排，但不能标视频闭环通过。全量数量/评分阈值留给 M4 执行。
