# 数字人慕课验收交付

读取根 [AGENTS.md](../../../AGENTS.md)、[M4 spec](../../../specs/M4-acceptance.spec.md)、[追踪表](../../../specs/TRACEABILITY.md) 和 [项目状态](../../../docs/PROJECT_STATUS.md)。

## 执行方法

1. 确认是预验收还是冻结指标后的正式验收。记录素材授权、样例摘要、设备、模型和配置；未冻结指标可以预验收，不假称正式通过。
2. 按 M4 数据数量及 AC01–AC18 执行，记录每条输入、预期、实际、证据和结论。按原始记录计算指标，不只展示汇总结果。
3. 内容、音色、形象、自然度、口型、字幕、连贯性和理解性分别验证。采样点和不可测排除规则可复核；教师确认不以模型自评替代。
4. 故障注入覆盖重复提交/消息、重启、取消、显存不足、超时、静音、缺服务与缓存失效；预检正确阻断不混入有效任务成功率。
5. 恢复成功保留首次失败记录。对失败项修复后复测相关能力；不因剩余有效样例足够而丢弃失败任务。
6. 验证访问控制、生命周期、独立环境、版本锁定和部署说明实际可用；提交演示、样例、配置模板和教师操作/异常说明。
7. 汇总全部 FR/NFR/AC 覆盖并更新项目状态。未通过指标或 P0 阻断明确列出，只有所有冻结退出条件满足才标首版完成。

测试证据记录真实提供方和审核版本；降级预览不计正式成功。敏感教师素材留在受控存储，记录摘要与访问位置，检查日志和配置不含密钥。

前序证据可以复用，但影响行为的代码、模型或配置变化必须复验相应项。源仓库演示、模拟测试和未经执行的检查清单不能替代本项目实测。
