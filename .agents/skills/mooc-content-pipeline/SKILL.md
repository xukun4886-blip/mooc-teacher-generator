# 数字人慕课内容链路

读取根 [AGENTS.md](../../../AGENTS.md)、[M2 spec](../../../specs/M2-content-pipeline.spec.md) 和 [项目状态](../../../docs/PROJECT_STATUS.md)，按相关工作项实施；涉及模型能力时参考 M1 的实际证据。

## 执行方法

1. 建立稳定项目、原页、片段标识和持久化版本。先固定来源/播放映射及审核快照，再接入工作台编辑。
2. 原页渲染与结构解析分开存储；用真实图表、公式、仅图片页检验异常提示。重排、合并、拆分保留来源，导入错位阻断。
3. 分别实现 AI、备注原文、外部稿。AI 吸收上下页上下文，原文/外部稿保持字面内容，空白或占位备注要求补充；AI 新版本不覆盖人工稿。
4. 分开保存显示文本、读法文本和控制事件；用区间、数组、引用和停顿一起验证，禁止通用括号清理。系统/项目/页面配置与批量覆盖范围可追溯。
5. 教师审核知识点、术语和理解问题后锁定版本；修改撤销相关确认并标媒体待更新。正式任务消费快照，不能被编辑中的新稿覆盖。
6. 接入已验证 TTS，逐页试听真实音频；预检阻断素材、映射、审核、服务或能力问题。记录证据、状态和本次尚未验证的链路。

验证重点是保存重开、三入口原文保持、外部错位、来源映射、审核版本、配置继承和符号保留；不要只对前端显示做快照测试。缺 TTS 时可先验证内容流程，音频退出条件仍未通过。

教学核查至少支持验收课时 5 个问题和来源追溯。模型评估提供线索，最终确认由教师完成。整片生成、字幕和任务恢复交由 M3 spec，不在本阶段偷偷扩入 P1 完整录音对齐。
