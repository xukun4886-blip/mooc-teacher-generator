## 阶段目标与依赖

消费 M2 的审核快照，完成真实语音、数字人、字幕、时间轴和课程合成。照片与视频路径各完成约 10 页、3 分钟课程，支持单页样片、整片预览和四类成果导出。

本阶段必须实现持久化任务、严格失败处理和缓存。前置为 M1 的真实模型能力及 M2 的稳定页/片段映射、审核和预检。M4 负责全量验收数据、评审和部署交付。

## 任务与状态契约

2026-10-08 用户规则更新：采用 [一键流程](ONE_CLICK_FLOW.md)，完整未审核草稿不受前置人工评审阻断。新增持久化制作记录接续真实媒体任务，上传形象自动选择路径；整课草稿采用课程画质，单页样片仍为720p。成片后的主动确认绑定真实文件和输入，不自动宣称正式通过，保留正式快照/样片及阶段退出验证。

区分项目状态、任务阶段和片段媒体状态，不能以一个浏览器状态代替持久化记录。

- 项目可表示草稿、素材校验、课件解析、待讲稿确认、待样片确认、排队、生成、合成、完成；失败和取消保留独立结果及发生阶段。
- Job 保存任务标识、审核快照/配置版本、当前阶段、总片段/完成片段/失败片段、重试次数、实际模型、耗时、错误及资源记录。
- Scene 分别记录语音、人物、合成状态与输出。生成可预览片段不代表全课完成；页面主动隐藏人物可记录该阶段“不需要”，仍须有效讲解和字幕。
- 请求提交返回 HTTP 202 与稳定任务标识。状态刷新从服务端恢复；WebSocket 断开退回状态查询。
- 幂等键基于审核输入与有效配置摘要；重复点击、重复消息复用同一逻辑任务，不产生重复正式成果。失败重试须有明确代次，保持来源任务关系。

文件输出建议采用临时文件写入、有效性校验、原子发布后再持久化完成状态。重启核对文件与记录，恢复未完成阶段；过期工作进程或旧任务版本的晚到结果不得覆盖新版本、失败或取消终态。

取消停止创建新子任务，运行片段在可中断点结束。对不支持即时中断的模型明确展示实际行为，不把取消任务标为完成。资源不足降低批次或暂停并提示，有限重试，不能无限循环。

## 媒体与时间轴约定

1. 语音输出记录真实时长，逐段拼接统一参数并检查漏句、重复、静音和音色跳变。
2. 人物输出使用同一份实际驱动音频；视频路径保留源序列动态。源视频循环仅为视觉基础，须重新依据当前音频驱动口型。
3. 页/片段起止由音频、明确停顿和转场确定；停顿不应产生未配置的重复音轨或双倍间隔。
4. 字幕显示审核文本，读法替换不应把发音辅助文本混入 SRT。对齐器处理显示文本与音频的对应，并记录不确定对齐项。
5. 默认合成 1080p、25 fps、H.264/AAC；支持 720p 预览及可选烧录字幕。保持比例，不拉伸课件。
6. 人物、字幕位置提供重点区域检查和人工确认，不能仅凭固定坐标宣称所有页无遮挡。

## 缓存依赖与失效范围

| 变化 | 必须失效或重算 | 可复用内容 |
| --- | --- | --- |
| 一片段读法/讲稿或语速变化 | 该片段语音、人物、字幕与合成；重算后续时间偏移 | 未改变输入的其他片段媒体 |
| 参考语音或 TTS 模型/权重/生成参数变化 | 所有受影响语音、人物、字幕和合成 | 原页、讲稿及无关项目媒体 |
| 人物素材或人物模型/权重变化 | 受影响人物及合成 | 已确认且输入未变的语音与字幕对齐 |
| 页图或人物位置/大小变化 | 受影响合成 | 语音、人物、相对字幕时间 |
| 人物显隐变化 | 合成及该页人物是否需要的编排；显示时若无有效缓存则生成人物 | 语音与字幕 |
| 前页实际时长或前后停顿变化 | 页级时间轴、后续绝对字幕偏移及整片拼接 | 后续输入未变的语音/人物媒体 |

摘要至少覆盖审核版本、读法文本、控制事件、参考语音摘要、代码/权重版本、有效参数；人物缓存追加源图/序列和实际音频摘要；合成缓存追加页图、字幕、布局及编码配置。只保存文件名或讲稿字符数不足以判断命中。

## 四类成果与质量门槛

- MP4：可解码、连续播放与拖动，包含原课件、当前教师形象及讲解；人物主动隐藏页例外有记录。
- SRT：UTF-8、审核显示文本、实际对齐时间戳；绝对时间与最终顺序一致。
- TXT/Markdown：按原页/片段映射组织，含页码、标题及审核稿。
- JSON Manifest：素材和输入摘要、审核/配置版本、实际提供方和代码/权重版本、缓存命中、逐页时间轴、文件检查、异常及生成时间。

正式完成前校验全部片段和最终文件，异常静音、空输出、截断或模型失败均导致失败。用户主动选择的普通配音/静态人物降级仅为标识清楚的预览，不计作正式成功。预检阻断与运行失败分别记录。
