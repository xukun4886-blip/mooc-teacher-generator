# 一键慕课制作改造（2026-10-08）

2026-10-09：高级设置新增可选[云端照片工作进程](CLOUD_PHOTO_WORKER.md)，课程默认本机，明确保存后仅照片/当前驱动音频交给指定服务器。三项上传、一键完整未审核草稿、播放下载、教师主动确认的主流程保持；连接检查不上传/生成，不用错误口型或降级媒体通过。

依据：用户本轮明确决定；复用 Vue + FastAPI、SQLite 和现有真实适配器，保留全部旧项目、素材、审核及证据。关联 M2-F01/F03/F04/F06、M3-F01–F06，FR01/FR02/FR05–FR19、NFR01/NFR03/NFR05–NFR08、AC01/AC02/AC08/AC09/AC11/AC14–AC17。原需求文档不修改。

## 具体改造与用户行为

1. `/` 为三项上传与“生成慕课视频”：照片/视频共用一个入口，课程 PPT、参考语音各一个。首次上传自动创建课程；展示原图/原视频、PPT 页数和原页缩略图、参考语音播放器。
2. `/?advanced=1&project=<id>` 保留原工作台：三种讲稿入口、逐页编辑、人工审核、试听、结构和布局、正式快照/样片/导出、真实模型能力检查。首页折叠“高级设置”提供继续课程、新课程和管理入口。
3. 在现有 SQLite 单个工作进程中持久化 `course` 制作任务，串行准备参考音色、缺失页讲稿，再接续原 `m3` 媒体任务。关闭浏览器不阻断制作。
4. 新课程默认原页顺序、普通话、语速 1、字幕开启、1080p、人物侧栏 25%、每页目标 45 秒；时长只是生成指导，实际时间由真实 TTS 决定。上传形象自动选择照片/视频路径，已有项目配置和人工稿保留。
5. 缺参考片段文字时，本机选取前 7.5 秒（不超过原长，至少 3 秒）并使用现有 Whisper 权重识别，保存自动来源，不视为人工核查通过。视频超过 60 秒时自动选取前 60 秒原视频序列；不足 5 秒失败。原件保留，高级入口可修正片段及文字。
6. AI 使用原页图、正文、备注、整课和邻页上下文，返回完整中文显示稿、读法稿及可校验逐句对应；只自动生成缺稿页，人工/外部/备注原文不被覆盖。人物由当前真实音频逐页驱动，字幕按真实语音时间。
7. 点击生成制作完整未审核草稿，不要求先审核讲稿、试听或样片。输出水印标识“未审核草稿”，保持 `preview=true, quality_verified=false`；全部片段和整片有效才显示完成。主界面播放下载 MP4，四类成果仍保留。
8. 成片后教师主动打开确认区，勾选已观看并确认；记录绑定视频摘要、输入摘要、操作者和时间。不自动改写逐页确认或正式验收状态，草稿文件和水印保留。修订后旧成片提示过期，禁止确认旧输入，审核历史保留。
9. 进度仅来自实际阶段及讲稿/语音/人物/合成页数，不估造百分比。中文失败原因、直接重试、最多三代执行；复用已保存讲稿及兼容的已校验媒体。素材失败可重试或更换。2026-10-09修复：课程空闲时，有效PPT也可直接“重新选择”；系统自动创建关联课程并切换，物理复制已就绪的所选人物和参考语音（含当前选取、对应文字），原课程/审核/成果保留。新课程不继承旧讲稿、来源页映射、审核或媒体缓存；原页重新解析/渲染，后续一键生成使用新课件。无需普通用户先进入高级入口或手动新建课程。任务运行/排队或素材处理中仍禁止更换。

## API 与持久化

- `POST /api/projects/{pid}/quick-assets/{role}`：复用真实上传检查，Multipart `file, revision`；界面说明上传使用范围，模式变化保留历史。已存在有效PPT时返回新课程的素材任务，`project_id`为新课程、`source_project_id`为原课程，前端持久保存并切换到该课程。旧revision/忙碌/空文件/已变更的教师输入会被阻断且不创建课程；解析失败保留在新课程，原课程不变。高级`assets/pptx`接口继续阻断覆盖有效PPT，保护旧映射。
- `POST /api/projects/{pid}/generate`：202；缺有效素材 422；原子查重并保存制作/媒体任务关系。
- `GET /api/projects/{pid}/generation`：最近制作状态、媒体进度、过期和成片确认；无记录返回 null。
- `POST /api/projects/{pid}/generation/{jid}/retry`：202；最多三代执行，保留失败历史。
- 2026-10-09讲稿格式修复：`generation`返回`retry_allowed`及AI错误的`source_page_index`，普通入口显示具体失败页并禁用用尽的重试。单页HTTP请求最多4次，429/503等待及最多2次格式纠正共用该上限；全部原始响应保留，顶层数组/混入输入、缺字段和`finish_reason=length`均不能发布讲稿。输出模式放入system指令，user只包含原课件上下文与原页图。完整正文可按明确句界恢复逐句对应，不补造缺失正文。
- 制作记录另存`draft_recipe`（格式契约、提供方及请求配置摘要）。仅尚无媒体结果且失败的记录，在实际契约/配置修复后允许新建一个有限制作任务；旧三代失败记录原样保留，从缺稿页继续。普通重复点击仍查重；单个任务最多三代。此摘要不进入已完成成果的输入摘要，配置修复不会使历史成片失效或改写教师确认。
- 2026-10-09第11页续修使用`complete-object-v3`来源资料边界与具体纠正上下文，免费视觉模型过滤未支持的输出/思考参数，原HTTP错误与逐次耗时留存，详见[M2契约](M2-content-contract.md)。不增加tokens或重试上限；不从嵌套大纲/数组抽取讲稿，不补造正文。首页用尽次数提示服务/生成配置修复后继续，高级编辑不是普通制作前置条件。

- 2026-10-09 `complete-object-v5`允许仅版面空白不同的两份完整正文按原文定位对应，继续采用实测语音时间，不改正文或猜测时长。实际修复后可严格重验证保存的真实响应；校验响应摘要、同一页来源/输入和基础版本，追加新版本并记录恢复来源，旧失败任务保持失败。普通流程仍自动消费完整当前稿后制作未审核草稿，无人工评审前置。
- `POST /api/projects/{pid}/generation/{jid}/confirm`：显式 `confirmed:true`，仅完整有效当前成片可确认；未完成422，内容变化409。
- `POST /api/projects/{pid}/asset-jobs/{jid}/retry`：失败素材处理再入队，须匹配当前素材。

复用 jobs、m3_reviews/m3_review_history 表，不清空旧数据。制作阶段重启重新入队，已保存参考选择和讲稿不重复生成；媒体阶段沿用 execution 隔离与恢复。制作期间拒绝高级编辑，媒体消费不可变输入副本。正式路径门槛保留；此次改变允许未审核草稿先生成、再成片确认。

## 验证边界

2026-10-09旧稿纯标点兼容：单独的闭括号/句号等非朗读标点并入相邻句的显示和读法区间，原文、数组、公式和控制事件不删除。新媒体提交保存合并后的完整对应，实际输入摘要随对应改变；已有耗尽任务保持失败。只有旧失败任务的对应确实需修正时，一键继续可建立新的有限制作/媒体任务；重复点击仍复用新任务，单任务三代上限不变。已完成且兼容的语音/人物/合成保留，只有标点的整段稿要求修稿，不据此制作空白成果。

2026-10-09讲稿链路启用`body-first-v1`：新制作固定分阶段配置；正文成功立即保存，本地派生读法/字幕对应，教学核查独立记录。`generation.teaching_pending`给出当前待核查页数，未审核草稿可按既有规则继续；正式审核/冻结不得通过pending。正文页失败后继续其他页，`page_failures`定位缺页；本次结束时汇总失败，不发布缺页整课。恢复只消费保存的兼容步骤，旧运行任务沿用旧契约。界面新增真实阶段名称与“仅重试教学核查”，未将人工核查移回普通制作前置。

2026-10-09 Lecture 8第17页纠正使用`complete-object-v6`，真实错误回答仅留证、不再回灌纠正请求；对象后额外文字明确提示，汉字读法例子消除拼音歧义。用尽重试的无媒体失败任务在实际契约更新后可继续，已完成页和旧失败保留；不以此增加无限重试或跳过坏页。

工程测试覆盖完整未审核制作、查重、缺输入中文错误、AI 部分失败/重试、恢复、正式冻结仍阻断、显式确认及修订失效。真实浏览器检查上传、两模式、刷新、播放下载和高级入口；真实两页短课记录实际提供方、当前音频驱动、文件解码/时长/静音和四类成果摘要。短课程不替代正式十页/约三分钟和教师质量评审。
