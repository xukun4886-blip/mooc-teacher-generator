# M3 媒体接口与执行契约 v1 · 2026-10-02

关联 M3-F01–M3-F06、FR08–FR15/FR17–FR19、NFR01–NFR04/NFR08、AC05/AC08/AC09/AC13–AC17。复用 [M2 契约](M2-content-contract.md) 的本机会话、原页和不可变快照，没有新建系统或 GPU 队列。

## 接口和审核

2026-10-09纯标点兼容：新提交将独立非朗读标点并入相邻完整句，保存覆盖所有显示/读法字符的对应和原区间；数组、引用、公式及未知符号不删除。TTS与字幕采用同一对应及实际语音分段时间，纯标点不单独触发原生推理。旧运行任务的输入快照不改写；旧失败对应确实改变时可经正常一键提交创建不同输入的有限新任务，保留旧耗尽任务与全部失败。兼容缓存继续校验复用。

以下路径沿用受保护的 `/api/projects/{pid}` 前缀；业务阻断 422、版本冲突 409、不存在 404。状态来自服务端，刷新及断连不依赖浏览器任务对象。

| 路径 | 方法和行为 |
| --- | --- |
| `/m1-review` | GET 原素材、当前选择、真实语音/照片和视频 A/B 样片及 11 项结论；POST `binding/checks/note/completed` 保存人工记录。未评项为 null，需修复为 false；完整且样片齐全才能保存 completed。不改写 M1 源证据、不自动宣告阶段通过 |
| `/m1-review/media/{id}` | GET 登记媒体，摘要/会话保护及 Range。原视频使用 H.264 浏览器播放副本；原件及模型驱动序列保留 |
| `/snapshots` | GET M2 正式快照索引，草稿不进入此表 |
| `/snapshots/{id}/layout-review` | GET 活动原页、布局、绑定及记录；POST `scene_id/binding/no_obstruction:true/note` 保存教师逐页重点区域核查 |
| `/media-jobs` | POST HTTP 202：正式 `snapshot_id`，单页样片可加 `scene_ids:[id]`；GET 完整历史。整课须 M1 当前人工评审、同快照/模型/配置的单页样片确认、每页布局确认 |
| `/media-jobs/{jid}` | GET 真实阶段、片段及分层状态、计数、耗时、错误和有效成果 |
| `/media-jobs/{jid}/cancel` | POST：排队立即取消；运行记录取消请求，当前原生调用到达边界后停止后续处理，晚到结果不发布 |
| `/media-jobs/{jid}/retry` | POST HTTP 202：仅失败任务，最多 3 代，保留来源及错误历史，复用通过校验的各层媒体 |
| `/media-jobs/{jid}/review` | POST：非草稿且完成的单页样片；identity_voice/lipsync_seams/subtitles_timing/layout_no_obstruction 四项 checks 全部 true 加人工 note，记录对应原页布局确认 |
| `/media-jobs/{jid}/exports/{kind}` | GET mp4/srt/script/manifest；仅 completed 且摘要有效，草稿下载名加 draft 前缀 |

草稿显式 `preview:true/revision`，可选真实 `mode:photo|video` 及活动页范围。实时项目复制到任务独立输入 `m3.draft.v1`，不会填写教师确认或进入 M2 快照表；720p、叠加 `DRAFT - NOT REVIEWED`，清单 preview:true/quality_verified:false。正式只读库内 `m2.snapshot.v1`，工程项目阻断，不能上传任意 JSON 冒充审核快照。

正式模式在 M2 配置中冻结，主动改模式须保存审计记录并重新预检/冻结；草稿 mode 仅记录测试路径。入队和执行核对素材、页图和模型；固定独立 M1 环境、代码/权重，TTS YAML 内容摘要也进入输入。M1 评审绑定素材选择、教师、模型及样片摘要，改变后过期。单页样片确认和每页布局核查均为教师操作。

## 字幕和编码

默认按完整句配对显示稿/读法稿；句数不同返回 `SUBTITLE_MAPPING_REQUIRED`。可传 `subtitle_units:{scene_id:[{display,reading}]}`，完整覆盖两稿及原顺序，不增补或删句。当前读法句结合独立控制偏移生成真实 TTS 子段，同引擎逐段合成，返回采样时钟的 speech_timeline/segment_index/start_seconds/end_seconds。显示句使用对应语音子段的实际区间，前后停顿不进字幕；控制标记不朗读，公式、数组及引用保持显示稿。

这是**实测合成句段级对齐**，不声称词/字级强制对齐或人工口型评分通过，不按字数/页数均分时间。有歧义须教师显式配对，实际教学对应和视听质量仍待人工核查。

每页 H.264/AAC、25 fps、48 kHz 双声道；正式默认 1080p，单页/草稿 720p。PPT 等比适配 16:9，`layout:overlay|sidebar` 沿 M2 项目/逐页继承；侧栏预留人物空间，小窗用逐页角落及尺寸。隐藏人物仍有语音和字幕。人物保持比例，只为帧边界短暂保持尾帧；不会循环第一段说话片。视频全序列送入 MuseTalk 并按当前音频重新驱动。

页时长为实际音频加向上对齐 25 fps 的显式尾部填充（0–0.04 秒），记录 frame_padding_seconds；语音/字幕区间不变，后页偏移取前页合成时长。拼接不额外新增停顿。重点区域须逐页人工核查，不能凭固定坐标声明无遮挡。

2026-10-09字幕画布修复：明确ASS PlayRes为实际输出宽高，字号随高度取height/30（1080p为36像素），避免SRT默认小画布把字号放大。保留显示正文及实际语音区间，不按字数重新切割时间。合成缓存版本升至`m3.compose.v3`，仅重合成，兼容语音和当前音频驱动人物可复用；历史成果不覆盖。真实第1页对照及两项媒体/局部失效检查通过，整课排版与人工质量需实际复验。

M1 普通人物样片 30 秒门槛保留；仅内部 `purpose:m3_segment` 支持 >=0.1 秒当前音频，没有补静音来满足样片门槛。

## 任务、缓存和生命周期

SQLite WAL 同一 jobs 表增加 kind:m3；持久化冻结输入、模型、generation/execution、scene、stage_states、错误、资源、耗时及恢复历史。M2 处理、试听、M3 GPU 共享唯一工作进程锁，初始串行。

input_key 覆盖冻结输入、路径、样片/整课类别、模型及字幕配对；重复提交返回同一逻辑任务。失败显式 retry；取消后明确新建。阶段发布要求 execution 令牌且数据库仍 running/未取消，旧消息/进程不能覆盖终态。各层媒体经摘要、全解码、异常静音及时长检查后原子发布。最终所有片段和整片有效才 completed；样片仍待确认，草稿不计正式成功。

语音缓存包含读法/分句、事件、语速/停顿、参考片段/文字、代码/权重/参数/YAML；人物追加实际当前音频 SHA-256、人物素材/路径/模型；合成追加原页、相对字幕、布局、编码及草稿标识。审核 ID 留在任务/清单；相同输入重新确认或只改显示稿/布局可复用兼容语音，不能因新快照 ID 全部失效。显示稿只重算字幕/合成，读法改变重做相关语音/人物/字幕/合成，前页时长改变只重算后页绝对偏移和整片。

重启将中断 M3 重新排队并校验缓存后继续；最多三次自动恢复。Windows 原生子树归属 KILL_ON_JOB_CLOSE Job Object，工作进程异常退出时其模型/FFmpeg 子树退出，避免孤儿 GPU 调用并行。取消不承诺模型即时中断；模型/合成有时限，资源不足和无效/静音/截断输出均失败，不降级人物或声音。

进度是实际阶段/有效/失败计数。耗时累计已记录检查点和运行实测，异常退出后最后检查点至死亡的时间不可恢复，明确记录限制。原生资源/日志在受控项目存储。本轮成功/失败/取消运行保留以供证据，不自动删除 M1 原始记录；临时发布文件清理。复制为独立文件且不继承正式任务/审核；删除无活动任务的项目同时清理缓存、任务、快照及评审历史，其他副本保留。

2026-10-09照片长音频内存修复：锁定SadTalker模型代码/权重保持，原生适配层每帧生成后将完整float预测detach转至CPU再由原模型拼接，防止GPU帧列表随时长累积；不改驱动音频、帧数、模型精度或人物尺寸。原生记录含frame_storage_policy及worker_sha256；首次OOM保留并在同一任务有限代次中恢复，既有有效页仍须摘要/解码校验。CPU内存消耗与长音频能力须实測，不声称无限容量或自动质量通过。

MP4、UTF-8 SRT、逐页 Markdown、JSON Manifest 使用同一审核版本/配置/原页映射/时间轴，下载再次检查摘要。清单含提供方、代码/权重、真实资源/时间、缓存原因、检查结果、异常和人工记录。
