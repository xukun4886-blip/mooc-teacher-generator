# M4 可用性与验收功能规格

状态：进行中（预验收，未通过）。版本：0.2。依据：V1.1 第 6、9–11、15–16 节。执行 Skill：[mooc-acceptance](../.agents/skills/mooc-acceptance/SKILL.md)。

2026-10-09：已启动[M4预验收与交付准备](../docs/evidence/M4/README.md)，指标未冻结，足额素材/人工评分/另机重建仍待条件。普通产品流程沿用[一键制作](ONE_CLICK_FLOW.md)，未审核完整草稿先生成、成片后教师主动确认；AC14的“未审核阻断”适用于高级正式生成，不阻断普通草稿，也不自动放行正式验收。退出条件不勾选。

## 阶段目标与输入

在 M1–M3 的真实闭环上修复问题，完成首版 P0 功能、非功能和质量验收，形成可部署、可复现、可操作的交付。

输入包括可运行应用、固定代码/权重/配置、前序证据、授权验收素材及评审人员。以下数量和阈值来自 V1.1 的建议验收目标；正式执行前记录用户确认的冻结版本。未冻结可以进行预验收，但不能宣称正式验收完成。

## 验收数据与评审

- 3 份授权课件，覆盖普通文字、图表和公式；至少 2 名授权教师。
- 照片与视频模式各 6 个有效基线任务，共 12 个；每项约 10 页、3 分钟。
- 另执行一次接近已配置上限的长任务，记录实际页数/时长及路径；不把“30 分钟建议上限”当成已验证性能承诺。
- 专项样例覆盖空备注、占位句、仅图片页、公式数组、外部稿错位、不可用模型和异常静音。
- 每个验收课时建立知识点清单和至少 5 个理解问题，答案可追溯；最终内容由教师确认。
- 五分制：1 分不可用，3 分可辨识但有明显瑕疵，5 分自然且接近参考。各维度独立评分，保留评分人和样片定位。

## AC01–AC18 执行规格

| 编号 | 验证内容 | 建议通过条件与证据 |
| --- | --- | --- |
| AC01 | 项目/素材/课件 | 上传、保存重开、删除可用；页数及页序 100% 一致；损坏、缺素材、格式不支持明确提示 |
| AC02 | 教学覆盖与正确性 | 对照教师知识点清单，最终覆盖率 ≥95%；关键术语、数值、公式无未修正实质错误；待确认项清零 |
| AC03 | 语音内容 | 逐句核对全部基线音频，无漏句、重复整句或不可理解片段；指定术语读法均由教师确认 |
| AC04 | 音色、形象与自然度 | 每位教师不少于 5 段 10 秒样片；本人及 2 名评审各维度评分；各维度平均 ≥3.5/5；分别保留原始评分 |
| AC05 | 两条人物路径 | 两条路径有效成片；视频模式保留原序列动态；无持续面部崩坏、明显身份漂移或不可用嘴部伪影 |
| AC06 | 口型同步 | 每条路径各 20 处清晰发音起点，逐帧与波形人工复核；至少 90% 可测点偏差 ≤200 ms |
| AC07 | 字幕、切页与遮挡 | 切页对应讲解；随机 20 句字幕起止偏差至少 90% ≤300 ms；人物与字幕不遮挡经确认的重点区域 |
| AC08 | 成果与结束时差 | 四类文件可打开，视频连续播放及拖动，无意外黑帧/截断；扣除明确片头片尾后音视频结束时差 ≤100 ms |
| AC09 | 局部重做与中断恢复 | 改一页只重做受影响媒体并重算后续时间轴；改布局仅合成；一次中断后复用有效片段恢复 |
| AC10 | 首次成功率与资源异常 | 12 个有效任务至少 11 个首次完成；其余定位后可恢复；取消、显存不足、超时可读；耗时及资源记录完整 |
| AC11 | 讲稿入口与映射 | 三种入口均测试；原文/外部稿除允许的读法配置外不改写；空备注无无关套话；页数或标识错位阻断 |
| AC12 | 教学符号与控制 | `[0,1]`、`[1,2,3]`、`[1]` 内容保留；明确停顿事件不朗读且按确认值生效 |
| AC13 | 逐页控制 | 至少 3 页不同位置/尺寸/显隐/停顿，验证默认与覆盖；隐藏人物仍有语音和字幕；重点无遮挡 |
| AC14 | 预检及估算 | 缺配置、输入不兼容、未审核稿在正式生成前阻断；无实测基线耗时/费用为未知；预检不触发付费生成 |
| AC15 | 严格失败处理 | 强制 TTS 和人物服务失败，注入可解码静音；任务失败，不以其他教师、普通声音或无人物替代为正式完成 |
| AC16 | 幂等与重启 | 重复提交、重复消息、生成中重启各一次；不重复正式成果；已完成片段可恢复；单片段失败则整课不完成 |
| AC17 | 缓存与时间更新 | 分别修改讲稿、参考语音、模型和布局验证失效范围；不同音频不复用同一说话视频；字幕/后续页随实际时长更新 |
| AC18 | 理解性与连贯性 | 每个基线课时 ≥5 题核查，答案/来源可追溯且无未修复矛盾；3 名评审连贯性、可理解性各平均 ≥3.5/5 |

评分聚合、字幕起止偏差统计和不可测点排除规则在冻结记录中明确，保留原始数据，避免只展示汇总分数。不能以自动相似度或模型自评替代听看检查与教师确认。

## 非功能验证

| 要求 | 可检查证据 |
| --- | --- |
| NFR01 持久化可靠性 | 重启前后数据库/文件对应、有效片段复用和未完成阶段恢复 |
| NFR02 资源控制 | 初始单 GPU 密集任务运行、队列等待、显存不足暂停/降批次及有限重试记录 |
| NFR03 可观测性 | 解析/讲稿/TTS/人物/合成耗时，冷热启动、峰值显存，界面操作不被生成阻塞 |
| NFR04 教学和视听质量 | 内容核查、教师评审、无异常静音及严格教师模式；对应 AC02–AC07、AC15、AC18 |
| NFR05 隐私与素材 | 授权确认、项目访问隔离、服务端密钥、未默认训练/共享、删除验证 |
| NFR06 兼容性 | 实际主流桌面浏览器列表与版本、MP4 播放、各模型独立环境重建验证 |
| NFR07 可维护性 | 能力声明和适配接口、代码/权重锁定、系统/项目/页面覆盖关系及配置模板 |
| NFR08 生命周期 | 日志含任务/阶段/耗时/错误且不泄漏密钥；取消/失败临时文件清理；项目删除关联成果 |

性能报告用固定设备/模型，分别记录两条路径 10 页约 3 分钟的首次加载与预热，统计总耗时/成片时长。首版不承诺实时生成；只报告实测，不以估算替代。

## 证据与统计规则

每条用例记录编号、样例摘要、任务/版本、有效配置、实际模型、预期、实际、结论、媒体或日志定位及修复复测结果。缺条件导致的正确预检阻断单独统计，不混入 12 个有效基线任务的首次成功率。

失败任务恢复成功应保留首次失败记录，不能计为首次完成。照片/视频身份不得因模式切换丢失；降级预览不得算入正式路径成功。教师素材与密钥不随测试记录默认进入公开仓库。
